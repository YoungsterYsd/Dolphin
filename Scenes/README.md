# Scenes 目录

| 子目录 | 内容 | 引入里程碑 |
|---|---|---|
| `Main/` | 入口主场景（M1 测试场景、M3 起为正式 MainScene） | M1 |
| `Characters/` | 角色预制（Player.tscn / Enemy_*.tscn / Boss_*.tscn） | M3 起 |
| `UI/` | HUD / 背包 / 暂停菜单 / 设置菜单 / Boss 血条 | M3 起 |
| `Levels/` | 测试关卡 / Boss 房 | M4 起 |

> 规则 R-DIR-01：场景文件（`.tscn`）只放本目录；脚本不混放（场景内脚本若文件名与场景一致除外）。
