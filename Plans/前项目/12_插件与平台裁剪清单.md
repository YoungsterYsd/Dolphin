## §7 附录 · 明确保留模块/目录清单（v1.1 新增）

> 本附录针对 Day 4 裁剪验证后，主理人后续询问的 `Source/RPGGame/Teams/` 与 `Source/RPGEditor/` 两个目录给出**整体保留**结论，并把同档次的"基础设施型"目录一并归档，避免后续再起讨论。

### 7.1 Source/RPGGame/Teams/ —— **整目录保留**

**作用**：基于 UE `IGenericTeamAgentInterface` 扩展的阵营/队伍系统。**单机 ARPG 必需**，不是"联机才用"。

| 类 | 类型 | 必需理由 |
|---|---|---|
| `IRPGTeamAgentInterface` | UINTERFACE | Character/PlayerState/AIController 都实现这个接口；删了等于全套阵营机制崩盘 |
| `URPGTeamSubsystem` | WorldSubsystem | 中心 API：`GetTeamForActor` / `CompareTeams`，**AI 索敌、伤害友伤过滤都要它** |
| `URPGTeamStatics` | BlueprintFunctionLibrary | 蓝图调用入口（HUD 蓝图/触发器 BP 都会用） |
| `URPGTeamDisplayAsset` | DataAsset | 队伍颜色/贴图配置；敌怪头顶血条变红、友方 NPC 变蓝就靠它的 `ApplyToActor` |
| `ARPGTeamInfoBase` / `ARPGTeamPublicInfo` / `ARPGTeamPrivateInfo` | Actor | 网络复制载体；单机 Demo 用 PublicInfo 即可，PrivateInfo 留作未来联机扩展 buffer |
| `URPGTeamCreationComponent` | GameStateComponent | 数据驱动地按 Experience 建队伍；每个副本 ActionSet 配 `TeamsToCreate` 即可 |
| `URPGTeamCheats` | CheatManagerExtension | 调试控制台：`CycleTeam` / `SetTeam` / `ListTeams`，开发期切阵营测试用 |
| `UAsyncAction_ObserveTeam` / `UAsyncAction_ObserveTeamColors` | BP 异步节点 | HUD 蓝图绑定队伍/颜色变化 → 自动刷新血条与材质 |

**直接影响的 RPG 模块**：
- 战斗（D03 DamageExecution 友伤过滤）
- AI（敌怪互不攻击）
- UI（敌人头顶血条颜色 / 小地图标记）
- Experience 配置（每个副本配自己的阵营列表）

**结论**：✅ **整目录 11 个类全部保留**。删任何一个都会引发连锁返工。

### 7.2 Source/RPGEditor/ —— **整目录保留**（不打入发布包）

**作用**：RPG 项目的编辑器扩展模块，仅在 UE Editor 进程加载，正式打包不包含。**改善团队开发体验，零运行时成本**。

| 子目录/文件 | 作用 | 必需理由 |
|---|---|---|
| `RPGEditor.h/.cpp` + `RPGEditor.Build.cs` | 模块入口；初始化 GameEditorStyle、注册 AssetTypeActions、注入 GameplayCue Editor 默认基类与路径推导 | 删了 GameplayCue Notify 创建体验严重下降 |
| `RPGEditorEngine.h/.cpp` | 自定义 UnrealEdEngine 子类。在 `DefaultEngine.ini` 通过 `EditorEngine=/Script/RPGEditor.RPGEditorEngine` 指定 | **删了 Editor 起不来**（已被 ini 引用）；提供 PIE 钩子让 ARPGWorldSettings.ForceStandaloneNetMode 生效 |
| `Validation/`（5 个 Validator） | UE5 DataValidation 框架：蓝图编译/加载警告/材质函数/源码控制四种校验，外加基类 UEditorValidator | 资产校验是 Lyra 工程"持续干净"的关键，**Demo 中后期资产爆量时尤其重要**；零配置可工作 |
| `Private/AssetTypeActions_RPGContextEffectsLibrary` + `RPGContextEffectsLibraryFactory` + `GameEditorStyle` | Content Browser 右键能新建 RPGContextEffectsLibrary 资产；自定义 Editor Slate 风格 | 反馈系统（D02）足音/材质音效特效库要用这种资产；删了 Content Browser 没法新建 |

**结论**：✅ **整目录 12 个文件全部保留**。零运行时开销，仅 Editor 进程加载。

### 7.5 这份附录的判定标准（给后续讨论提供参照）

每当出现"这个 Lyra 类要不要保留"的疑问，按以下顺序判断：

1. **被 .ini 直接引用**（如 EditorEngine/GameEngine/AssetManager 类指向）→ **必保留**
2. **被 RPGGame 主链路 .cpp #include**（且不能轻易解耦）→ **必保留**
3. **属于 GAS / Modular / Experience / Teams / Cosmetics / UI 这类核心基础设施** → **必保留**
4. **零运行时成本（只在 Editor 加载）+ 与团队开发体验强相关** → **必保留**
5. **与已被裁剪插件强绑定**（如 Hotfix/Gauntlet/Replay）→ 已删，无需再议
6. **能用 1~3 行 git 历史回滚就找回的辅助代码** → 删掉减负，需要再恢复
