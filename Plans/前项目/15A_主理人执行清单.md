### ③ `B_RPG_UIPolicy`（CommonUI 策略蓝图）

> ⚠️ **必须先建 ④ 再建 ③**！  
> CommonGame 原版 `UGameUIPolicy::GetWorld()` 在 CDO 编辑时会触发 `CastChecked<UIManagerSubsystem>(GetOuter())` Fatal 崩溃。  
> AI 已经在 `RPGGame` 模块新增了 `URPGUIPolicy` 子类（override 了 GetWorld 做 CDO/Archetype 安全保护），**你必须用这个 RPG 子类作为父类**，不要用原始 `GameUIPolicy`。

```
路径：  /Game/UI/RPG/
父类：  RPGUIPolicy （✅ RPG 子类，不是原始 GameUIPolicy！）
做法：
  1. 右键 → Blueprint Class
  2. "Pick Parent Class" 对话框 → All Classes ☑ 
     → 搜 "RPGUIPolicy" 或 "RPG UI Policy"
     → 选它（注意：搜 "GameUIPolicy" 会有 2 个结果，选 RPGUIPolicy 那个）
     → Select
  3. 命名 B_RPG_UIPolicy

打开蓝图（双击）→ Class Defaults：
  ☑ Layout Class                  = B_RPG_PrimaryGameLayout    (现在可以安全填了)
  ☑ Local Multiplayer Behavior    = OnePlayerPerScreen

✅ Compile + Save
```

> 💡 如果搜 "RPGUIPolicy" 没结果：
> 1. 关 Editor 重启（让新 dll 生效）
> 2. Pick Parent Class 对话框右下角 "Show All Classes" ☑

> 💡 **只能用 `RPGUIPolicy` 作父类**。如果你不小心选了原版 `GameUIPolicy`，建出来后点 LayoutClass 下拉会立即 Fatal 崩 Editor。

### ④ `B_RPG_PrimaryGameLayout`（CommonUI 分层 Layout）

```
路径：  /Game/UI/RPG/
父类：  PrimaryGameLayout (CommonGame 插件，Editor 搜 "Primary Game Layout")
做法：  右键 → User Interface → Widget Blueprint → All Classes 勾上
       → 搜 "Primary Game Layout" → 命名 B_RPG_PrimaryGameLayout
```

#### ④.1 Designer 拼 4 层 Stack

```
[Canvas Panel]                            (根)
  ├─ CommonActivatableWidgetStack         重命名 → Stack_Game        (Anchor 全屏 / ZOrder=0)
  ├─ CommonActivatableWidgetStack         重命名 → Stack_GameMenu    (Anchor 全屏 / ZOrder=1)
  ├─ CommonActivatableWidgetStack         重命名 → Stack_Menu        (Anchor 全屏 / ZOrder=2)
  └─ CommonActivatableWidgetStack         重命名 → Stack_Modal       (Anchor 全屏 / ZOrder=3)
```

> ⚠️ 4 个 Stack 在 Designer 树里**必须勾选 "Is Variable"**（默认就是 ✅，确认即可），
> 否则 Graph 里调不到。

> 💡 Stack 子控件的 Details 面板里**没有 LayerTag 字段**——LayerTag 不是配出来的，
> 而是在 Graph 里用 `RegisterLayer(Tag, Stack)` 函数注册。

#### ④.2 Graph 里写 4 行 RegisterLayer 节点（关键！）

打开蓝图 Graph 面板，加一个 **Event Construct**（My Blueprint → Functions → Override → Construct），然后串联 4 个 RegisterLayer 节点：

```
Event Construct
   │
   ├──► Register Layer
   │      Layer Tag    = UI.Layer.Game        (下拉里搜 "Game"，选 UI.Layer.Game)
   │      Layer Widget = Stack_Game           (拖左侧 Variables → Stack_Game)
   │
   ├──► Register Layer
   │      Layer Tag    = UI.Layer.GameMenu
   │      Layer Widget = Stack_GameMenu
   │
   ├──► Register Layer
   │      Layer Tag    = UI.Layer.Menu
   │      Layer Widget = Stack_Menu
   │
   └──► Register Layer
          Layer Tag    = UI.Layer.Modal
          Layer Widget = Stack_Modal
```

**操作详解（一次配 1 个 Layer 的 5 步）**：

1. Graph 面板空白处右键 → 搜 "Register Layer" → 选 `Register Layer (Common Game)`
2. 该节点的 **Layer Tag** 引脚右侧下拉框 → 输入 "UI.Layer" → 选 `UI.Layer.Game`
3. 左侧 My Blueprint 面板 → Variables → 拖 `Stack_Game` 到 Graph → 选 "Get"
4. 把 Stack_Game 的输出引脚连到 RegisterLayer 节点的 **Layer Widget** 引脚
5. 把 RegisterLayer 节点的执行链（白色三角）连到上一个节点（或 Construct 入口）

重复 4 次，4 个 Layer 全部串完。

#### ④.3 编译保存

```
1. 工具栏 → Compile (Ctrl+P) → 应当全绿，无 warning
2. 工具栏 → Save (Ctrl+S)
3. ✅ 完成 ④。下一步去做 ③ 创建 B_RPG_UIPolicy，用 RPGUIPolicy 子类作父类，可以安全填 Layout Class = B_RPG_PrimaryGameLayout
```

> ⚠️ 编译时如果报 "Stack_Game must be public" → 选中 Variable → Details → Variable → Instance Editable ☑ 或 Expose on Spawn ☑ 任一即可。

> ⚠️ 4 个 Button 在 Hierarchy 面板里**必须勾选 "Is Variable"**（默认就 ✅，确认即可）。否则 Graph 里调不到。

#### ⑤.2 Class Defaults 配置（位置说明）

打开蓝图后，**点顶部工具栏的 "Class Defaults" 按钮**（图标是个齿轮 / 或 Window → Class Defaults），右侧 Details 面板会切换为类默认值。

找 **"Input"** 分组（这是 RPGActivatableWidget 暴露的）：

| 字段 | 设为 | 备注 |
|---|---|---|
| **Input Config** | `Menu` | 切到菜单输入：UI 接管键鼠/手柄、3D 世界停止响应输入 |
| **Game Mouse Capture Mode** | （任意） | 当 Input Config=Menu 时，C++ 内部强制 `NoCapture`，这里设啥都行 |

> 💡 之前清单里写的 "Auto Set Focus" 这个字段 RPGActivatableWidget 没有暴露，**忽略它**。
> 焦点行为通过下面 ⑤.4 的 GetDesiredFocusTarget override 来控制，更精准。

#### ⑤.3 Graph 节点（4 个 Button OnClicked）

打开 Graph 面板，左侧 Variables → 点击 `btn_start` → 右侧 Details 面板找 "Events" → 点 **OnClicked** 旁边的 [+]，自动生成事件节点。同样操作给其他 3 个按钮，最终 4 个 OnClicked 节点：

```
[On Clicked (btn_quit)]   ─►  [Quit Game] (Quit Preference: Quit, Force Quit ☐)

[On Clicked (btn_start)]  ─►  [Print String "TODO: A2-7 进入 L_TestArena01"]

[On Clicked (btn_select)] ─►  [Print String "TODO: A5"]

[On Clicked (btn_set)]    ─►  [Print String "TODO: 接 SettingScreen"]
```

#### ⑤.4 ⚠️ 修复 "GetDesiredFocusTarget wasn't implemented" 编译警告

Widget Blueprint 编译会出现警告：
```
GetDesiredFocusTarget wasn't implemented, you're going to have trouble using gamepads on this screen.
```

这是 CommonActivatableWidget 的强制要求 —— 手柄/键盘焦点必须有默认目标，否则手柄玩家按 A 按到空气。**修复方法**：

```
1. 蓝图编辑器左侧 My Blueprint 面板 → Functions
2. 鼠标悬停 "Functions" 一行的右侧 → 出现 "Override" 下拉按钮
3. 点 Override → 搜 "Get Desired Focus Target" → 点它
4. 自动跳转到生成的 GetDesiredFocusTarget 函数（带 ReturnNode）
5. 把 btn_start 拖入函数体 → 选 "Get btn_start"
6. 把 btn_start 节点的输出引脚连到 ReturnNode 的 "Return Value" 引脚

完成后函数体应该是：
   [Function Entry]─────────────►[Return Node (Return Value: btn_start)]
                                       ▲
                                       │
                                  [Get btn_start]
```

```
1. 工具栏 → Compile (Ctrl+P) → 应当全绿，警告也应该消失
2. 工具栏 → Save (Ctrl+S)
```
