## 2. 各包详细方案

### 2.1 A4-P1 · TopDown 相机

#### 设计

```
[Player Capsule]
  └─ SpringArm (offset 0,0,80 = 头顶)
      ├─ TargetArmLength = 1200 (默认距离)
      ├─ Pitch = -60° (俯角，从地面上方往下看)
      ├─ Yaw = 0° (固定不旋转，纯俯视角；不跟玩家朝向转，避免眩晕)
      ├─ bUsePawnControlRotation = false
      ├─ bDoCollisionTest = false (室内地图不需要避免穿墙)
      └─ Camera (FOV = 60° 标准三人称)
```

#### 实现选项

| 方案 | 优点 | 缺点 | 推荐 |
|---|---|---|---|
| **A**：写新类 `URPGCameraMode_TopDown` 继承 `URPGCameraMode` | 接 Lyra CameraMode 栈，未来切相机模式（普通战斗 / Boss 房 / 过场）原生支持 | 多 100 行代码 | ✅ |
| B：直接在 `ARPGCharacter::SetupSpringArm` 写死 | 30 行搞定 | 后续切模式要重构 | ❌ |

**选 A**。CameraMode 栈是 Lyra 标准，A6 死亡相机/Boss 镜头需要它。

#### 配置项（DataAsset 驱动）

新建 `DA_CameraMode_TopDown_Default`（继承 `URPGCameraMode_TopDown`）：

| 字段 | 值 | 说明 |
|---|---|---|
| FOV | 60° | 标准 |
| Pitch | -60° | 俯角 |
| TargetArmLength | 1200 | 默认距离 |
| MinDistance | 800 | 滚轮拉近极限 |
| MaxDistance | 2000 | 滚轮拉远极限 |
| ScrollSpeed | 100 | 每滚轮一格变化的距离 |

#### 滚轮缩放接线

- 新建 `IA_CameraZoom`（Axis 1D Float，鼠标滚轮）
- IMC_RPG_Default 加一行 `MouseWheelAxis → IA_CameraZoom (Negate)`
- HeroComponent 接 IA_CameraZoom → 调 CameraMode.AdjustTargetArmLength(Delta * ScrollSpeed)

#### 验收标准

- [ ] **P1-V1** PIE 启动 → 相机俯视玩家，距离 1200，俯角 60°
- [ ] **P1-V2** 滚轮上 → 相机靠近玩家（距离 → 800 极限）；滚轮下 → 相机拉远（距离 → 2000 极限）
- [ ] **P1-V3** 玩家移动时相机平滑跟随，不会卡顿；玩家旋转时相机 Yaw 不跟着转
- [ ] **P1-V4** 切回主菜单（A2 已有）→ 相机恢复主菜单状态

### 2.2 A4-P2 · 方向键移动 + 移动方向=朝向

#### 设计要点

按 02 v3 锁定：

| 输入 | 行为 |
|---|---|
| ↑（W）| 屏幕**正上**方移动（世界 +Y 或 -Y，看相机朝向）|
| ↓（S 在 02 是闪避）| 屏幕**正下**方移动 |
| ←（A）| 屏幕**正左**方移动 |
| →（D）| 屏幕**正右**方移动 |
| 斜按 | 8 向移动（同时按两键）|

> **冲突预警**：02 锁定的"S = 闪避"和 IMC_RPG_Default 现有的 IA_Move 默认值是否冲突需查 IMC 配置。**A4-P2 阶段先用方向键 ↑↓←→**，WASD 预设留给 A4 后或 A5（设置菜单做时再加）。

#### 朝向规则（02 §6 锁定）

- **移动时**：`RPGCharacter.YawRotation = ATan2(MoveInput.Y, MoveInput.X)` —— 角色面向移动方向
- **静止时**：保留上次朝向（不立即回正）
- **战斗中朝向辅助**：A5 普攻 GA 自动锁敌（最近 5m 敌人）；A4 不做

#### IMC 配置（Editor 修改）

打开 `IMC_RPG_Default`：

| Mapping | Key | Modifiers |
|---|---|---|
| IA_Move | ↑ Up | Swizzle Input Axis Values (YXZ) |
| IA_Move | ↓ Down | Negate (Y), Swizzle |
| IA_Move | ← Left | Negate (X) |
| IA_Move | → Right | （无） |

> 关键技巧：`Swizzle YXZ` 把 W/S 按键的 1D 轴值映射到 Y 轴；`Negate` 反转方向。Lyra 标准做法。

#### 代码改动

| 文件 | 改动 |
|---|---|
| `RPGHeroComponent.cpp::InitializePlayerInput` | 已实现，确认 BindNativeAction 接 `IA_Move → MoveAction`（A2 已就位，验证一下）|
| `RPGCharacter.cpp::Input_Move` 或 HeroComponent 等价函数 | 新增/确认：`AddMovementInput(WorldDir, Magnitude)` + `SetActorRotation(FRotator(0, Yaw, 0))` |

#### 验收标准

- [ ] **P2-V1** PIE 按 ↑ → 角色向屏幕上走；按 → 向右走；按 ↑+→ → 斜走
- [ ] **P2-V2** 角色身体面朝移动方向（Capsule 模型有面朝感）
- [ ] **P2-V3** 松开方向键 → 角色停下，**朝向保持上次方向**
- [ ] **P2-V4** 不响应鼠标输入（鼠标移动不影响角色朝向 / 不响应右键）
