```
  Step 2: Apply GE_HealthSet_Init (Instant)
          → StaminaMax=100, StaminaCurrent=100
  Step 3: Apply GE_Health_Derive_Max (Infinite AttributeBased)
          → HealthMax = HealthBase × (1 + HealthMul) + HealthBonus = 100
  Step 4: Apply GE_Attack_Derive_Final (Infinite AttributeBased)
          → AttackFinal = 10
  Step 5: Apply GE_Defense_Derive_Final (Infinite AttributeBased)
          → DefenseFinal = 10
  Step 6: Apply GE_Health_Init_Full (Instant + AttributeBased)
          → HealthFinal = HealthMax（此时 HealthMax 已是派生后的最终值）
  Step 7: Apply GE_Stamina_Regen_OutOfCombat (Infinite Periodic 0.1s)
          → 脱战时 StaminaCurrent += 1.0/0.1s
  Step 8: Apply GE_Stamina_Regen_InCombat (Infinite Periodic 0.1s)
          → 战斗中 StaminaCurrent += 0.0/0.1s（词条用，默认 0）
```

**关键**：Step 6 的 `GE_Health_Init_Full` 必须在派生 GE 之后，保证 `HealthMax` 已是最终值而非 0。

### 3.5 DamageExecution 完整公式（按旧案 13 行 + 事件化）

```
# === Capture ===
[攻方]: AttackFinal, CritChance, CritDamage, DefensePenetration, DamageBonus, LifeSteal
[守方]: DefenseFinal, DamageReduction, StaminaCurrent (读)
[守方 Tag]: RPG.State.Block.Blocking / RPG.State.Block.PerfectBlocking
[守方 GE]:  GE_Block_State 的 SetByCaller(Block.DamageReduction / Block.StaminaConsume)
[SetByCaller]: Damage.Base, Damage.AttackerScalingCoef

# === §6 暴击判定 ===
isCrit  = random() < CritChance
critMul = isCrit ? (1 + CritDamage) : 1.0

# === §7 未减免伤害 ===
rawDamage = (DamageBase + AttackFinal × AttackerScalingCoef) × critMul

# === §8 承伤率（防御穿透）===
effectiveDef = DefenseFinal × (1 - DefensePenetration)
absorbRate   = 500 / (500 + effectiveDef)

# === §11 最终伤害基础 ===
finalDamage = rawDamage × absorbRate × (1 + DamageBonus) × (1 - DamageReduction)

# === 格挡分支 ===
if Target.HasTag(RPG.State.Block.PerfectBlocking):
    finalDamage = 0
    # 仅广播事件，不做副作用（订阅方各自处理：耐力奖励 / 强化 Buff / 飘字 / 特效 / 反震）
    Broadcast GameplayMessage RPG.Message.Block.PerfectTriggered {
        Instigator:      攻击者 Actor
        Target:          被攻击者 Actor
        DamageBlocked:   原 finalDamage
        AttackSourceTag: SourceTag
        HitLocation:     HitResult.Location
    }
    # A3 阶段无订阅方（Block GA 空壳）；A5 Block GA 订阅 Apply 耐力+20 GE + 强化 Buff GE

elif Target.HasTag(RPG.State.Block.Blocking):
    dmgRed      = Target.GE(GE_Block_State).GetSetByCaller(Block.DamageReduction)
    staminaCost = Target.GE(GE_Block_State).GetSetByCaller(Block.StaminaConsume)
    finalDamage *= (1 - dmgRed)
    AddOutputModifier(HealthSet.StaminaCurrent) -= finalDamage × staminaCost
    # Stamina=0 的破防广播由 HealthSet.PostGameplayEffectExecute 触发

finalDamage = max(1, finalDamage)

# === §12 吸血 ===
if LifeSteal > 0 and finalDamage > 0:
    AddOutputModifier(HealthSet.HealthHealing) += finalDamage × LifeSteal

# === 输出伤害 ===
AddOutputModifier(HealthSet.HealthDamage) += finalDamage

# === 飘字广播 ===
Broadcast GameplayMessage RPG.Message.Damage.Popup {
    Target, Amount=finalDamage, IsCrit, IsBlocked, HitLocation
}
```

**A3 预留不接入的字段**：`BreakBonus`（韧性，A5 武器时接）、`AttackSpeed`（普攻速度，A5 武器时接）。
