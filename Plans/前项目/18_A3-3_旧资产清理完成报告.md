## 2. 详细清理项

### 2.1 `URPGCombatSet` C++ 类废弃

**原因**：A3 v7 设计把 `BaseDamage` / `BaseHeal` 两字段迁移成 —— BaseDamage 走 `SetByCaller.Damage.Base`（由技能注入），BaseHeal 走 `SetByCaller.Heal`。AttributeSet 不再承担这两个临时字段。

**操作**：

| 文件 | 操作 |
|---|---|
| `RPG/Source/RPGGame/AbilitySystem/Attributes/RPGCombatSet.h` | 🗑️ 删除 |
| `RPG/Source/RPGGame/AbilitySystem/Attributes/RPGCombatSet.cpp` | 🗑️ 删除 |
| `RPG/Source/RPGGame/Player/RPGPlayerState.h` | ✏️ 移除 `CombatSet` 成员声明 |
| `RPG/Source/RPGGame/Player/RPGPlayerState.cpp` | ✏️ 移除 `#include "RPGCombatSet.h"` + `CreateDefaultSubobject<URPGCombatSet>()` |
| `RPG/Source/RPGGame/Character/RPGCharacterWithAbilities.h` | ✏️ 同上 |
| `RPG/Source/RPGGame/Character/RPGCharacterWithAbilities.cpp` | ✏️ 同上 |
| `RPG/Source/RPGGame/AbilitySystem/Executions/RPGHealExecution.cpp` | ✏️ **重构**：从 Capture `URPGCombatSet::GetBaseHealAttribute()` 改为 `Spec.GetSetByCallerMagnitude(RPGGameplayTags::SetByCaller_Heal)` |
| `RPG/Config/DefaultEngine.ini` | ✏️ 删除 1 条 CoreRedirect（`LyraCombatSet` → `RPGCombatSet`） |

**HealExecution 关键改动**（对比）：

改前（24 行 + FHealStatics）：
```cpp
struct FHealStatics {
    FGameplayEffectAttributeCaptureDefinition BaseHealDef;
    FHealStatics() {
        BaseHealDef = FGameplayEffectAttributeCaptureDefinition(
            URPGCombatSet::GetBaseHealAttribute(),
            EGameplayEffectAttributeCaptureSource::Source, true);
    }
};
// ... ExecutionParams.AttemptCalculateCapturedAttributeMagnitude(HealStatics().BaseHealDef, ...)
```

改后（17 行）：
```cpp
// 不再 Capture，直接读 SetByCaller
const float BaseHeal = Spec.GetSetByCallerMagnitude(
    RPGGameplayTags::SetByCaller_Heal, false, 0.0f);
```

**优点**：
- 删除 CombatSet 后不需要调用方先 `ApplyGameplayEffect(GE_SetBaseHeal)` 再 `ApplyGameplayEffect(GE_Heal)` 两步
- 一次 Apply 即可，通过 SpecHandle 注入 → `URPGHealExecution` 直接读
- 与 §3.5 伤害公式里 `RPG.SetByCaller.Damage.Base` 模式完全对称
