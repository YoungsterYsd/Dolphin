## §4 Plugins 插件清单（每个插件解决什么问题）

按"基础设施 / UI / 输入 / 游戏框架 / 工具"5 类分组。**所有插件均在 RPGGame.uproject 中启用**（通过 §3.7.1 验证）。

### 4.1 基础设施插件（GameFeature 框架核心）

| 插件 | 模块类型 | 解决什么问题 | FDRPG 是否必要 |
|---|---|---|---|
| **GameFeatures** | 引擎自带 | GameFeature Plugin 系统的核心运行时——支持运行时加载/激活插件、Plugin 互相依赖检查、生命周期 | ⭐ **必要**（DP-1 保留基础设施） |
| **ModularGameplay** | 引擎自带 | GameFrameworkComponentManager + ExtensionEvent，支持运行时往 Actor 注入 Component 与 Ability | ⭐ **必要**（DP-1 + Lyra Experience 依赖） |
| **ModularGameplayActors** | Lyra 自定义 | AModularCharacter / AModularPawn / AModularGameMode 基类，集成 ModularGameplay 的 4 阶段初始化（Spawned → DataAvailable → DataInitialized → GameplayReady） | ⭐ **必要**（RPG 主角直接派生 AModularCharacter） |
| **AsyncMixin** | Lyra 自定义 | 异步加载混入器（FAsyncMixin），用于 Experience 加载、Game Feature 加载这些异步流程的回调管理 | ⭐ **必要**（Experience 加载链依赖） |
| **GameplayMessageRouter** | Lyra 自定义 | 全局事件总线（UGameplayMessageSubsystem）—— 解耦的消息广播/订阅系统，比 Delegate 更灵活 | ⭐ **必要**（飘字、UI 事件、强化触发用它通信） |

### 4.2 UI 框架插件

| 插件 | 模块类型 | 解决什么问题 | FDRPG 是否必要 |
|---|---|---|---|
| **CommonUI** | 引擎自带 | 跨平台 UI 框架——CommonButton、CommonTextBlock、ActivatableWidget、PrimaryGameLayout 分层栈、统一手柄/键鼠输入路由 | ⭐ **必要**（DP-6 全用） |
| **CommonGame** | Lyra 自定义 | CommonUI + GameFramework 的桥接——CommonGameInstance、CommonPlayerController、CommonGameMode 基类，挂载 PrimaryGameLayout | ⭐ **必要**（B_LyraGameInstance 派生于此） |
