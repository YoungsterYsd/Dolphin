## 1. 主理人决策原文

> *"万界副本类似无限恐怖之类的无限流小说背景设定。玩家为了活下去以及探索无限乐园的秘密而穿梭。"*
> —— 主理人 2026-01 第四轮答复

**关键词解析**：
- **"万界副本"**：核心玩法载体——穿梭不同世界的副本
- **"无限恐怖类"**：明确参考《无限恐怖》zhttty 开创的"主神空间 + 电影/小说副本"范式
- **"无限乐园"**：本作的"主神空间"代称
- **"活下去"**：短期动机（生存驱动）
- **"探索秘密"**：长期动机（好奇驱动）
- **未明确**：乐园形象、副本类型、玩家身份、其他穿梭者、叙事载体——需策划补足

## 2. 一句话 Pitch

> **"普通人被神秘力量卷入'无限乐园'，在一个个光怪陆离的万界副本中浴血求生，拼死揭开乐园背后的真相。"**

### 2.1 Pitch 要素分解

| 要素 | 作用 |
|---|---|
| "普通人" | 玩家代入点——不是天选之子 |
| "神秘力量卷入" | 解释"为何穿越"的黑箱（无需详细解释） |
| "无限乐园" | 世界观专有名词 |
| "光怪陆离的万界副本" | 暗示美术要**风格多变**（奇幻/科幻/废土/神话） |
| "浴血求生" | 战斗玩法基调 |
| "拼死揭开真相" | 长期目标、剧情钩子 |

### 2.2 给美术 / 音乐的风格方向

| 维度 | 定位 |
|---|---|
| 整体基调 | 暗黑奇幻 + 克苏鲁暗流（乐园的未知感）+ 各副本的风格跳变 |
| 主角基调 | 凡人、带着伤痕、没有超能力（纯靠装备和技巧）|
| "无限乐园"视觉 | 诡异、宏大、非人、几何不自然（参考：SCP 基金会、《恐怖世界》）|
| 副本视觉 | **每个副本一个完全不同的视觉语言**（核心卖点）|
| 音乐基调 | 乐园主题：低频不安 + 教堂唱诗混响；副本音乐：随副本主题大幅变化 |

## 3. 核心设定（无限流标准模板）

### 3.1 主神 / 乐园的形态

| 维度 | 推荐设定 |
|---|---|
| **乐园的形态** | **无形、规则即神**（推荐）—— 乐园是一个"规则集"，没有具体人格/形象。玩家只能通过"公告"、"任务"、"奖励结算"等界面化方式感知它的存在 |
| **玩家如何感知乐园** | UI 弹窗 / 冰冷的系统音 / 存档点的水晶发光 / 副本开启时"悬浮金色卷轴" |
| **乐园的动机** | 未知（长期悬念）—— Demo 阶段暗示"它在观察""它在筛选""它在喂养"三种可能，不给答案 |
| **乐园的"发言"风格** | 简洁、冷淡、像系统提示（"副本已开启"、"目标已完成"、"奖励已发放"）|

**同类参考**：
- 《无限恐怖》的"主神"：有人格、会惩罚 → ❌ 本作不这样
- 《恐怖世界》的"网络"：系统化、冷冰冰 → ✅ 本作接近
- SCP 基金会的"规则"：文档化、中立 → ✅ 本作接近

**为什么推荐"无形"**：
1. 省美术资源（不需要主神角色建模、动画、配音）
2. 留足悬念（Demo 不揭秘，正式版大揭露）
3. 冰冷的系统感与"回档复活"设定天然契合（玩家死了是被乐园"重启"）

### 3.2 副本机制

#### 3.2.1 穿梭机制

| 项 | 设定 |
|---|---|
| 如何被选中 | 被乐园"标记"——每个玩家角色背景里都有一个被标记瞬间（Demo 阶段走"街上走着突然掉进去"的经典套路）|
| 如何进入副本 | **从初始点（中央枢纽）点选副本入口 → 开启仪式 → 瞬移到副本**|
| 副本内规则 | 每个副本一个"规则集"（Demo 阶段不强调规则差异，主要是场景/敌人不同；v1.0 可加"这个副本禁用某种武器"等 rule）|
| 奖励机制 | 击败关卡 Boss → 结算奖励：Meta 货币 + 永久解锁 + 本局临时物品 |
| 失败惩罚 | **死亡回档**（详见 03 文档），状态回滚到最近存档点；无永久扣除 |

#### 3.2.2 副本类型

| 维度 | 推荐 |
|---|---|
| **是否用影视/小说改编？** | ❌ **强烈不推荐**（版权风险见 §11）|
| **是否用游戏衍生（如致敬暗黑/魔兽）？** | ❌ 不推荐（版权风险 + 显得山寨）|
| **是否用神话题材（希腊/北欧/中国）？** | 🟡 谨慎使用（神话大多公有，但具体角色名要注意）|
| **是否用纯原创世界？** | ✅ **Demo 强烈推荐** |
| **策划推荐做法** | **原创世界 + 使用经典桥段类型**（如"中世纪地下城"、"克苏鲁深海"、"赛博朋克城市"），**给原创命名**，不沾任何已有 IP |

**核心原则**：副本可以"**类似某某风格**"（赛博朋克风、克苏鲁风、中世纪风），但绝不使用任何已有作品的角色、地点、专有名词。

### 3.3 玩家同伴 / 竞争者

| 项 | Demo 设定 | 未来扩展 |
|---|---|---|
| 是否有其他穿梭者（NPC）| ✅ 有 | — |
| 他们的关系 | **初始点有 3~5 个友方 NPC 穿梭者**（商店/任务/剧情/训练）| 扩展更多 |
| 副本内是否遇到其他穿梭者 | ❌ Demo 不做 | v1.0 可加"副本内偶遇陌生穿梭者，随机友好/敌对" |
| 敌对穿梭者 | ❌ Demo 不做 | v2.0 可加"Boss 房出现"强力敌方穿梭者作为秘密 Boss"|
| 多人联机 | ❌ Demo 不做 | v2.0+ 考虑 |

**设计意图**：初始点有 NPC 穿梭者是**关键**——他们承载世界观的**口述历史**（"我曾经也进过那个副本..."），解决"玩家为什么要探索秘密"的动机问题（其他穿梭者一样在探索）。

### 3.4 死亡即回档的设定解释

> **关键**：03 文档的"状态回档式死亡"需要世界观合理化，不然玩家会感觉机械。

#### 3.4.1 推荐设定："乐园的强制回收"

**叙事**：
> *"乐园的规则禁止参与者真正死亡。当参与者的生命体征归零，乐园会将其意识拉回最近一次'确权时刻'，并抹除确权之后的所有变化。"*

**关键点**：
- "确权时刻" = 存档点（存档点 = 乐园确认玩家状态的时刻）
- "死亡被抹除" = 回档，这是乐园**强制**的，玩家不能拒绝
- **暗示**：玩家是被乐园"圈养"的，不是它的"恩赐"——为长期剧情（反抗乐园）埋线

#### 3.4.2 Demo 阶段如何呈现

| 时机 | 表现 |
|---|---|
| 首次激活存档点 | 文案："乐园确认了你的状态。这成为了一个不可抹除的节点。" |
| 首次死亡 | 文案："乐园的权限将你从死亡之前拉了回来。你察觉到一丝异样。" |
| 连续死亡 | 文案逐步加重，暗示"乐园的耐心正在消磨" |
| 存档点外死亡 | 正常回档 |
| 死亡计数器（剧情用，非机制）| 暗示"死亡次数过多会发生什么"——Demo 不兑现，留悬念 |

#### 3.4.3 这个设定的剧情钩子

- **引子 1**："如果乐园能回档，那它为什么还要让玩家战斗？"
- **引子 2**："乐园真的能永远回档吗？是不是有上限？"
- **引子 3**："有没有穿梭者发现过'回档失败'的瞬间？"
- **引子 4（长期）**："回档的我，还是原来的那个我吗？"

Demo 阶段只播下这些种子，不揭晓答案。

### 3.5 "秘密"的方向

主理人说"探索无限乐园的秘密"。Demo 阶段给一个**引子**即可：

**推荐 Demo 引子**：*"乐园为什么要筛选穿梭者？它'选中'的标准是什么？"*

- 初始点 NPC 会提到这个疑问
- 每个副本 Boss 死前会说一两句有意味的话（"乐园...在找..."之类的）
- Demo 最后一个 Boss 战后解锁一段"乐园日志"碎片，给玩家"下一步探索"的钩子

**秘密的全貌**（不在 Demo 里揭示，只做内部设定）：
- **倾向 A**：乐园是某种高维文明的"游戏"——玩家是玩物
- **倾向 B**：乐园是人类意识的集合潜意识——玩家是为了"集体成长"而受难
- **倾向 C**：乐园是某个神明的"祭坛"——玩家的死亡是在供养它
- **倾向 D**：乐园是末日前的训练营——外界文明要灭亡，需要强者

**推荐倾向**：**A + D 混合**。既有"被玩弄"的无力感（动机：反抗），又有"末日训练"的希望（动机：变强）。

## 4. 玩家身份与动机

### 4.1 玩家身份

| 维度 | Demo 推荐 |
|---|---|
| 身份类型 | **普通人 + 意外卷入**（最省叙事成本）|
| 职业背景 | **留白或轻设定**（如"一个下班回家的普通上班族"），玩家可代入 |
| 是否有名字 | Demo **不给默认名**，玩家自起；或给一个中性代号（如"穿梭者 027"）|
| 是否有详细背景 | Demo **不写**，只暗示"在现实世界失去了某些东西"（引子，不展开）|
| 角色外观 | Demo 阶段：**1 套默认皮肤**，通用中性形象（见美术 brief）|

**参考案例**：
- 《Hades》：**有身份**（冥王之子 Zagreus），有明确名字和家庭——**反例**，本作不做
- 《挺进地牢》：可选 4 个角色，每人一点背景——**Demo 可学**
- 《死亡细胞》：**完全留白**，角色是无头尸 + 寄生体——**Demo 可学**（极简）
- 《空洞骑士》：沉默主角，身份通过环境暗示 —— **Demo 推荐学这个**

### 4.2 动机分层

| 层级 | 时间尺度 | 内容 | Demo 必答 |
|---|---|---|---|
| **短期动机** | 每个房间 / 每场战斗 | 活下去、清怪、拾宝 | ✅ |
| **中期动机** | 每个副本 / 每关 | 击败副本 Boss，解锁下一副本 | ✅ |
| **中长期动机** | 通关所有 Demo 副本 | 获得"探秘权限"——乐园开放下一层 | ✅ |
| **长期动机** | 正式版 | 揭开乐园真相、反抗 / 逃离 / 共生 | ❌ Demo 不答 |

**中期动机详解**（Demo 必答）：

主理人说"活下去 + 探索秘密"这两者都是长期的。Demo 必须给一个**清晰的中期目标**，否则玩家通几局就不知道自己在干嘛。

**推荐中期目标**：
> **"击败第 3 个副本的 Boss，解锁'乐园档案室'，阅读第一份关于乐园的文件碎片。"**

- 具体、可达成、有仪式感
- 与"探索秘密"直接挂钩
- Demo 通关 = 一个小高潮
- 留钩子："文件碎片只是一小部分，更多秘密需要更多挑战"

**参考 Hades**：逃离冥界见母亲——**具体、有仪式感**。本作对标这个清晰度。

## 5. ⏸️ 副本主题设计（挂起，代码框架落地后再定）

> **⏸️ 内容挂起说明（v3.1 原则）**：主理人第五轮明确"数值节奏、新手引导等不是代码搭建阶段需要考虑的，可以等基础代码框架落地后再进行设计"。副本的**具体主题 / 视觉风格 / 敌人类型 / Boss 设计 / 叙事节拍**属于典型的"内容"范畴，本阶段挂起。
>
> **工程搭建阶段只需**：代码架构支持"副本 = 房间树结构"、"副本 DataAsset 驱动"、"多副本并存与切换"（见 05 文档 §5 关卡与房间骨架），**不需要**实现任何一个具体副本内容。
>
> 本节下方的 4 个副本主题（破碎钟楼 / 锈蚀工厂 / 溺亡之歌 / 永燃废墟）保留作为"未来内容回填时的参考设计"。

### 5.1 设计原则

1. **视觉风格差异化最大**——玩家每进一个新副本都要有"哇"的感觉
2. **完全原创**——名字/角色/专有名词都自造，避免版权
3. **氛围跨度大**——从温暖到冰冷、明亮到黑暗、现实到超现实
4. **敌人类型匹配主题**——每个副本的怪物要符合世界观
5. **Boss 性格鲜明**——Boss 战是副本的记忆点

### 5.2 Demo 副本主题清单（推荐 4 个）

#### 副本 1：**破碎钟楼**（奇幻 / 新手副本）

| 维度 | 设定 |
|---|---|
| 内核参考 | 黑魂初始村 / 艾尔登法环史东薇尔 |
| 氛围 | 中世纪奇幻、黄昏、雾气、古老石砌 |
| 视觉关键字 | 破败钟楼、藤蔓、石像、生锈的铁门、黄昏光 |
| 敌人类型 | 骸骨战士、游魂、腐化骑士 |
| Boss | "钟声守护者" —— 一个身着破败盔甲、挥舞巨锤的骨王 |
| 音乐 | 钟声 + 管弦乐低音 + 吟唱 |
| 新手教学用 | ✅ 这里教玩家所有基础操作 |
| 叙事节拍 | 初始点 → "这是乐园给你的第一个副本" → 打完 Boss → "乐园的第一道门打开了" |

#### 副本 2：**锈蚀工厂**（赛博朋克 / 科幻）

| 维度 | 设定 |
|---|---|
| 内核参考 | 《2077》风 + 底特律：变人 + 原神米卡斯机关城 |
| 氛围 | 霓虹灯、下雨、蒸汽、金属、电流 |
| 视觉关键字 | 生锈管道、全息投影、破损机器人、蓝紫色霓虹 |
| 敌人类型 | 防卫机器人、电锯蜘蛛、失控 AI |
| Boss | "0x7F 老总" —— 一个机械 + 人类混合的庞然大物，多段攻击切换 |
| 音乐 | 电子鼓点 + 合成器 + 金属撞击 |
| 特色机制 | 地板有电流陷阱、环境互动（破坏油桶爆炸范围伤害）|
| 叙事节拍 | NPC 透露"那里的机器曾经是人"——悬念 |

#### 副本 3：**溺亡之歌**（克苏鲁 / 海洋恐怖）

| 维度 | 设定 |
|---|---|
| 内核参考 | 克苏鲁神话 + 《血源》猎梦篇 + 海底 |
| 氛围 | 深海、昏暗、沉没教堂、不可名状的低吼 |
| 视觉关键字 | 触手、沉船、珊瑚、发光水母、蓝绿色调 |
| 敌人类型 | 深潜者、触手怪、腐化教徒 |
| Boss | "无名之歌" —— 一个庞大的触手生物，身体一半沉没一半浮现，吟唱让屏幕扭曲 |
| 音乐 | 低频水声 + 唱诗班混响 + 扭曲的女声 |
| 特色机制 | 视野限制（雾气/墨汁）、"疯狂值"（靠近 Boss 屏幕扭曲）|
| 叙事节拍 | 进入时乐园警告"**注意：本副本含有不可观测实体**"—— 暗示乐园自己也忌惮它 |

#### 副本 4：**永燃废墟**（废土 / 末日 / Demo 最终副本）

| 维度 | 设定 |
|---|---|
| 内核参考 | 《辐射》风 + 《最后生还者》+ 暗黑不朽罪恶深渊 |
| 氛围 | 焦土、灰烬、夕阳如血、残破现代建筑 |
| 视觉关键字 | 废弃汽车、断裂高楼、灰色沙尘、血色天空 |

## 6. ⏸️ 叙事载体与工作量评估（挂起）

> **⏸️ 内容挂起说明**：叙事载体（环境叙事 / 档案碎片 / NPC 对话 / 过场动画）的**具体配比、具体工作量、具体文字量**属于内容范畴。工程搭建阶段保证"对话系统 / 档案系统 / 过场系统的代码骨架可用"即可。

### 6.1 四种叙事载体对比

| 方案 | 内容 | 工作量 | 主理人投入 | Demo 推荐 |
|---|---|---|---|---|
| **A 环境叙事** | 场景暗示（断剑、血迹、日记碎片散落）| 低（美术工作为主）| 低 | ✅ **必做** |
| **B NPC 对话** | 初始点 NPC + 副本内偶遇 NPC | 中（需编剧、配文）| 中 | ✅ **必做**（初始点）|
| **C 弹出文字日志** | 死亡搁浅式右下角文字 | 低（系统展示）| 低（编剧）| ✅ **必做**（首次事件触发）|
| **D 过场 CG / 静帧** | 关键节点播放动画或插画 | 高（美术、动画）| 高 | 🟡 **可选**（Demo 最终 Boss 后一个 30 秒过场）|

### 6.2 Demo 推荐组合

**组合 = A + B + C + D（简版）**：

| 场景 | 用哪种叙事 | 工作量估算 |
|---|---|---|
| 初始点 NPC 对话（3~5 个 NPC，每人 5~8 句话）| B | 编剧 ~200 字/NPC × 5 = 1000 字 |
| 副本内环境暗示（破碎家具、血迹、壁画）| A | 美术素材，无文字 |
| 关键事件弹出文字（首次死亡、首次存档、首次 Boss 击败等 10 个关键节点）| C | ~300 字 |
| Boss 战前后独白（每个副本 Boss 2~3 句）| B | ~300 字 |
| Demo 最终 Boss 击败后 30 秒静帧叙事 | D（简版，3~5 张静帧 + 旁白文字）| 美术 3~5 张画 + 旁白 ~500 字 |
| "乐园档案室"的碎片文字 | C | ~500 字 |

**Demo 总文字量估算**：**2500~3000 字**（非常轻量）

**参考**：
- Hades：文字量巨大（>10 万字），每个 NPC 每局都有新对话
- **Demo 本作**：初始点 NPC 每人 5~8 句固定 + 关键事件弹幕即可，保持轻量

### 6.3 工作量评估

| 项 | 工作量 | 负责方 |
|---|---|---|
| NPC 对话文本 | 3~5 天 | 编剧 / 主策 |
| 环境叙事资产需求（壁画/尸体/日记）| 美术工作的 5% | 美术 |
| UI 文字弹幕系统 | 1~2 天 | 工程（需 UI 组件）|
| 过场静帧（3~5 张）| 5~10 天 | 美术（插画外包）|
| 整体文案校对 / 本地化准备 | 2 天 | 主策 |
| **总计** | **~3 周 1 人** | 主策 + 美术 + 1 工程 |

**结论**：Demo 叙事体量工作量 **3 人周**左右，完全可控。

## 12. 验收标准

1. **一句话 Pitch 能说清游戏**：抽查 5 位测试玩家，看完 Pitch 能复述核心概念（世界观/玩法/动机）。
2. **专用词表一致性**：Demo 全部 UI / 对话 / 教程使用 §8 的专用词，无混用（如"篝火"与"节点"并存）。
3. **4 个副本视觉差异化达标**：4 张副本标志图并排，普通玩家能感受到"这是 4 个完全不同的世界"。
4. **初始点功能完整**：观测塔包含 4 个 NPC + 4~5 个功能区 + 档案室开放机制。
5. **中期目标清晰**：开局 15 分钟内玩家能说出"我要做什么"（击败 4 个 Boss 进档案室）。
6. **死亡回档的世界观解释能被玩家感知**：首次死亡的文案让玩家理解"为什么我能复活"。
7. **无版权风险**：所有专有名词、美术、音乐通过内部版权审稿。
8. **Demo 文字总量 ≤ 3500 字**：不臃肿、不冗长。
9. **NPC 对话被测试者认为"有吸引力"**：50% 以上测试玩家会主动点 NPC 听完全部对话。
10. **最终"档案室"碎片能埋下续作钩子**：测试玩家通关后想"更多秘密"。

## 13. 开放问题清单

以下问题本次未拍板，供主理人下轮决策：

### Q1：是否需要多周目递进？

| 选项 | 说明 |
|---|---|
| a. 无多周目 | Demo 不做，通关即结束 |
| b. 2 周目（Hard）| 难度提升 + 新 Boon + 新结局 |
| c. 无限周目 + 难度递增 | Hades 式"热度系统" |

**策划倾向**：Demo 做 **a**（通关后回到观测塔，玩家可重复刷副本刷资源），v1.0+ 加 c。

### Q2：世界观与肉鸽强化如何对接？

- 每个 Boon 是否有"世界观文案"？（如"火焰之拥：乐园的第 37 条规则碎片"）
- 是否有"反馈诅咒"类 Boon（双刃剑）？剧情上是"乐园的调戏"？

**策划倾向**：每个 Boon 配 1 句世界观短文案（词条池设计时统一规划，本文档不展开）。

### Q3：主角是否有背景故事？

| 选项 | 说明 |
|---|---|
| a. 纯白板（玩家代入）| Demo 推荐 |
| b. 预设身份（名字+背景）| 叙事更强，但失代入 |
| c. 可选 2~3 个角色，每人一点背景 | 工作量中 |

**策划倾向**：Demo 选 **a**；v1.0 可考虑 c。

### Q4：初始点观测塔是否会随进度变化？

- 通关副本后观测塔是否会出现新 NPC / 新装饰 / 新区域？
- 这是"观测塔逐步解锁"的感觉，增加进度感

**策划倾向**：**Demo 做轻量版**——通关每个副本后观测塔某个角落多 1~2 件"战利品展示"（如 Boss 武器放在展示台），不做完整区域解锁。

### Q5：是否做"死亡日志"？

- 玩家每次死亡后是否记录"你在 XX 副本被 XX Boss 击杀"
- 可以做成成就 / 档案室的"穿梭者日志"
- Hades 有类似机制

**策划倾向**：Demo 不做（§9 文字量上限），v1.0 加。

### Q6：档案室的内容体量？

- Demo 通关后开放档案室
- 里面的内容：1 段碎片文字（~500 字）？多段碎片？每通关一次增加 1 段？
- 未来扩展：所有副本的"乐园档案"汇总

**策划倾向**：Demo 放 1 段主线碎片（~500 字 + 意象图）+ 每通关一个副本后解锁该副本的"碎片文字"（4 个碎片 × 100 字 = 400 字），总 ~1000 字。

### Q7：穿梭者 NPC 之间是否有关系网？

- 观星人和吟者认识吗？
- 他们之间有对话互动吗？

**策划倾向**：Demo 不做（工作量大），只在观星人的单独对话里偶尔提到"某某人"（即吟者的名字）作为彩蛋。
