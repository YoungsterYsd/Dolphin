| 决策点 | 选择 |

### Event Kind 清单（写入 `SkillEventKind.gd` 常量）

| Kind | payload 示例 | 处理路径 |
|---|---|---|
| `&"hitbox_enable"` | `{node_path: "HitboxComponent", damage_node_index: 0}` | TimelinePlayer 直接管 caster 的 HitboxComponent.enabled = true，并把 damage_node_index 存到 caster.set_meta |
| `&"hitbox_disable"` | `{node_path: "HitboxComponent"}` | 同上反向 |
| `&"sfx_play"` | `{sfx_id: &"hit_01"}` | EventBus.skill_event_sfx → AudioManager 订阅 |
| `&"vfx_spawn"` | `{vfx_id: &"slash_blue", offset: Vector3(...)}` | EventBus.skill_event_vfx → VFXSpawner（M8 实装）订阅 |

| `&"camera_shake"` | `{intensity: 4.0, duration: 0.15}` | EventBus.skill_event_camera_shake → CameraRig 订阅 |
| `&"hit_stop"` | `{duration_ms: 80.0}` | EventBus.skill_event_hit_stop → HitStopHost 订阅 |

**状态**：✅ 已完成（待验收）

### 代码清单

| 文件 | 类型 | 内容 |
|---|---|---|
| `Script/SkillSystem/SkillTimelinePlayerHost.gd` | Node 子节点（GameInstance 下） | `play(timeline, caster, target=null) -> int (handle_id)` / `stop(handle_id)` / `_process(delta)` 推进所有 ActiveTimeline |

## 风险点 & 工程注意

- **@tool 不能用 Autoload**：所有 SfxBank / VfxBank 配置须 Dock 自己 `load(...)`；
- **AudioStreamPlayer 在编辑器进程能放声**（已验证）；必须默认 mute=false 但提供静音开关，避免改 timeline 时反复鸣响；

- **R-LOG-01 例外**：编辑器进程沿用 `print()` / `push_error`，不依赖 GameLogger；
- **R-EVENT-01**：编辑器进程不 emit 真实 EventBus 信号，所有"路由"在 Dock 内本地走方法调用，与运行时完全隔离。
