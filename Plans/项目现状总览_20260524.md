### 2.4 关键能力对照（一句话总结）

- **战斗管线**：`InputAction → ASC.try_activate → Ability_TimelineDriven → SkillTimelinePlayerHost.play → Hitbox.hit_landed → HitDamageResolver → DamagePipeline → ASC.apply_effect → AttributeChanged → HUD/Cue` — **全链路打通**。
- **数据驱动**：所有玩家可见数值（属性成长 / 伤害 / GE 模板 / 配置） 走 ConfigCenter；M11 道具/掉落已经走 CSV 双轨；M10 即将把更多 .tres 切到 Excel→JSON。
- **HUD/UI**：CommonUI 风格分层（8 CanvasLayer）+ HUDLayout 热切（Default/BossRush/Cutscene 三套）+ 21 个 Widget 全部组件化 + UIExtensionSubsystem 槽位插拔。
- **HD-2D**：全 3D 节点（CharacterBody3D + AnimatedSprite3D billboard + GridMap），SpringArm3D 俯视相机（pitch=-55°），SSAO/Bloom/Fog 全开，DOF 待办。
- **编辑器扩展**：`addons/skill_editor` 完整时间轴可视化（动画轨 + 事件轨 8 Kind + 实时预览动画/音效/VFX/震屏/顿帧）。
