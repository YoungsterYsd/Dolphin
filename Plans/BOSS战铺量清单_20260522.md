## 1. UI 界面布局改造（仅限布局）

> 已有：`HUD_Main.tscn` 8 层 CanvasLayer + 7 Slot；`HUDLayout_Default.tres` / `HUDLayout_BossRush.tres` / `HUDLayout_Cutscene.tres`；13 widget 完成。
> 思路：**优先复用**已就位的 HUDLayout_BossRush，只补 BOSS 战专属布局缺口。

### 1.1 Boss 顶部血条（LayeredBossHealthBar）— 🟡 已实现，需调位 + 入栈
- 当前 `Scenes/UI/BossHealthBar.tscn` 仍直接挂在 BossRoom_01 的 `HUDLayer` 内，未走 HUDLayout/Slot。
- **改造内容**（仅布局）：
  1. 把 `BossHealthBar` 改造成符合 `HUDWidgetMount` 的 widget 场景（已是 BaseWidget）
  2. 在 `HUDLayout_BossRush.tres` 增加一个 `m_bosshp` mount，挂到新增 Slot **TopCenterBoss**（与 ComboWidget 不冲突）
  3. `HUD_Main.tscn` Layer L1_HUD 下补一个 Slot 节点 `TopCenterBoss`（屏幕上沿 5%~12%，宽度 70% 居中）
  4. 主血条 + ghost 追条 + 500 血分隔线视觉已实现，仅微调位置和尺寸（高 24px / 圆角 4px / 主红 ghost 黄）
  5. 加 **Boss 名称 Label**（血条上方，字号 22，配色读 UIColorTokens.boss_name）
  6. 加 **阶段标记**（血条左侧 3 颗菱形宝石，按 phase 0/1/2 点亮，订阅 `EventBus.boss_phase_changed`）

### 1.2 BOSS 出场 Banner（BigBannerWidget）— ✅ 已就位，需触发 + 调样式
- `BigBannerWidget.tscn` 已挂载到 BossRush 布局 Center Slot，订阅 `EventBus.hud_big_banner_requested`。
- **改造内容**：
  1. 文案样式：BOSS 出场用大字号（48px）+ 描边 + 渐入 0.4s + 停留 1.2s + 渐出 0.5s（参数读 `UIDurations.tres` 的 L 档）
  2. 副标题位（"试炼之厅 · 第一形态"）
  3. 进场 BGM 切换的卡帧时机要和 banner 文字弹出对齐（详见 §2.1）
  4. **业务侧 DEP-10**：`boss_room.gd` 加 `_on_player_entered_arena` 时 emit `hud_big_banner_requested.emit(&"boss_intro", boss_name)`

### 1.3 阶段切换提示（复用 BigBanner / Toast）— 🔴 需新增触发链
- `BossAI.gd` 已 emit `EventBus.boss_phase_changed`，但**没有任何 widget 订阅**它播 banner。
- **改造内容（无新 widget，仅订阅）**：
  - `BigBannerWidget` 增加订阅 `boss_phase_changed`，phase 1/2 时弹"二阶段 / 终焉"banner
  - 或者用 `ToastWidget` 顶部条纹"BOSS 进入第二阶段"（更轻量）
  - **建议**：phase 1 用 Toast，phase 2 用 BigBanner（强调最终阶段）

### 1.4 BOSS 战结算 UI — 🔴 全新
- 当前 BossRoom 死亡只 emit `level_completed`，没有结算面板。
- **新建 widget**：`Scenes/UI/Widgets/BossClearWidget.tscn`
  - 全屏半透明黑底 ColorRect
  - 中央：「VICTORY」大字 + 击杀时长 + 受到伤害 + 输出伤害 + Combo 峰值 + 奖励列表
  - 底部按钮：「返回主城」/「再战」
- **HUDLayout 接入**：BossRush 布局新增 `m_bossclear` mount → Slot `Modal`，priority 高（=100），默认 enabled=false 由业务侧 push
- **InputContext 切换**：弹出时 push `Modal.tres`，关闭时 pop（已就位，复用 DEP-13 模式）

### 1.5 死亡 / 失败 UI — 🟡 仅有 GameOverLabel
- 当前 `BossRoom_01.tscn` 用纯 Label "GAME OVER 按 R 重开"，太简陋。
- **改造内容**：
  - 新建 `Scenes/UI/Widgets/DeathScreenWidget.tscn`：黑屏淡入 1.5s + "YOU DIED" 大字（红色）+ 「重试 / 返回」按钮
  - HUDLayout_BossRush 加 mount → Slot `Modal`，订阅 `EventBus.player_died`
  - 同时 push `Dead.tres` InputContext（复用 DEP-11）

### 1.6 BOSS 战专属 HUD 元素增强 — 🟡 部分占位
- **HitVignetteWidget**：已就位，BOSS 重击命中玩家时强化效果（订阅 `damage_dealt_v2`，instigator==boss && amount>20% maxHP 时 alpha+0.3）
- **ComboWidget**：已就位，确认在 BossRush 布局有挂（✅ TopCenter）
- **BuffListWidget**：已就位，BOSS 给玩家上 debuff（如灼烧、击退减速）时显示 debuff 列表（业务侧需触发 GE_Burning_3s 等）

### 1.7 BOSS 技能预警条 / 读条（QTE 雏形）— 🔴 重要新增
- BOSS 三阶段需要至少一个 **大招读条 / 危险预警**，否则无法做"识破→闪避"的可交互玩法。
- **新建 widget**：`Scenes/UI/Widgets/BossCastBarWidget.tscn`
  - BOSS 头顶下方 2D 投影位置（用 WorldProjector 投影）
  - 蓝→红渐变 ProgressBar + 技能名 Label + 倒计时数字
  - 订阅新增 `EventBus.boss_cast_started(boss, skill_id, duration)` / `boss_cast_finished(boss, skill_id)`（**EventBus 需新增 2 信号 → 见 §3.4**）
- **HUDLayout 接入**：BossRush 布局加 mount → Slot `Center`（上半区）

### 1.8 危险区域指示（地面光圈 / Telegraph）— 🔴 重要
- 当 BOSS 释放范围技能时，地面需要预警光圈（半秒后才落下）。
- **不是 HUD widget**，而是 **3D 场景内的 Decal/Mesh**（属于"美术资源"，详见 §2.4）。
- 但 HUD 侧需要加 **Boss Cast 名提示横条**（复用 §1.7）。

### 1.9 锁定 / 索敌指示 — 🔴 可选
- 玩家攻击/翻滚需要明确朝向 BOSS。
- 方案 A：玩家自动面朝最近敌人（不需要 UI）
- 方案 B：BOSS 头顶加锁定箭头（用 `WaypointArrowWidget`，已就位 DEP-6，业务侧调 `set_target(boss)` 即可）
- **建议**：MVP 先做 A，BossClear 后再加 B
