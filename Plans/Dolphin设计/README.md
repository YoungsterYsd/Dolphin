## 共同的工程原则（4 篇文档统一执行）

1. **架构锁定，数值挂起**——所有"具体伤害值 / 能量值 / 关卡间隔"用前项目源文档默认值占位，落地后再调，不在本阶段讨论。
2. **配置可热改**——字段结构必须支持从 `.tres` / `.json` 读取，不允许硬编码到 .gd。
3. **预留扩展接口**——尤其是武器双形态（妥协 A → 完整 → Aspect）、格挡耐久（`block_regen_rate_in_combat` 默认 0）、仓库容量（默认 -1 无上限）三处，必须写成"未来只改数据不改代码"。
4. **Cheese 防守 P0**——04B 文档的 10 条铁律必须每条在代码评审 checklist 里勾选。
5. **不联网假设**——Demo 单机 → 所有 `FFastArraySerializer / Replicated` 概念全砍，用 `Dictionary + signal`。
