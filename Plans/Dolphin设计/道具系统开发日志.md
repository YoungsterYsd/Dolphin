#### 遇到的问题 + 修复

##### 问题 1：FragmentRegistry const 引用类对象
**症状**：`Parse Error: Assigned value for constant "REGISTRY" isn't a constant expression.`
**原因**：Godot 4.6 的 const 不允许引用用户 GDScript 类（`Fragment_Currency` 等）。
**修复**：改 `const REGISTRY` 为 `static var _registry_cache + _build_registry()` 延迟初始化。
