## 架构（一张图）

```
NPC 对话 EffectNode "start_quest"
        │
        ▼
EffectHandlerRegistry.dispatch(start_quest)
        │
        ▼
StartQuestHandler → QuestSystem.accept(quest_id)
        │
        ├─ ConfigCenter.get_quest_def("res://Data/Manual/Quests/<id>.tres")
        ├─ GameInstance.quest_states[quest_id] = {state: active, objectives: {...}}
        └─ emit EventBus.quest_started + 初始 quest_objective_changed
                │
                ▼
        QuestTrackerWidget 显示「● 村长的请求 / · 击杀史莱姆: 0/3」
                │
                ▼ （玩家击杀 Slime）
        EventBus.enemy_died(slime)
                │
                ▼
        QuestSystem._on_enemy_died → 比对 entity_id="slime_lv1" → advance_objective
                │
                ▼
        emit quest_objective_changed(slay_slimes, 1, 3)
                │
                ▼
        QuestTrackerWidget 刷新「· 击杀史莱姆: 1/3」
                │
                ▼ （3/3 时 _try_complete_if_done）
        emit quest_completed
                │
                ├─ QuestSystem 分发 reward（toast / tag / xp / gold ...）
                └─ QuestTrackerWidget ✓ 完成 + 5s 淡出
```

## 用户手测路径

1. 进游戏（TestArena），走到村长身边
2. 按 **G** → 对话「啊，新来的旅人！…」→ Enter 推进
3. 选 **「我愿意帮忙」** → 对话推进 → effect_set_var → effect_start_quest（**这一步触发 QuestSystem.accept**）→ 谢谢话
4. 对话结束后**右上方应出现 QuestTracker**：
   ```
   ● 村长的请求
     · 击杀史莱姆: 0/3
   ```
5. 同时**右上方 Toast** 弹「**接受任务：村长的请求**」（2.5s）
6. 走到村东，按 **A** 攻击 Slime → 击杀 1 只 → QuestTracker 自动刷新「**1/3**」
7. 击杀全部 3 只 → 「**3/3**」变绿 → ✔ 标记 → Toast「**任务完成：村长的请求**」+ 5s 后淡出
8. 再次找村长按 **G** → 走 again_meet 分支「辛苦了，旅人。…」

### Cheat 测试
- **Shift+F7** → 直接强制完成 `quest_slay_slimes`（跳过击杀流程，验证 reward 分发）
