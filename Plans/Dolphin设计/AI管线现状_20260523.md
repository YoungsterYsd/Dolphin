# AI 管线现状（LimboAI 单管线）— 2026-05-23

Dolphin 的怪物 AI 仅有一条管线：**LimboAI v1.7.0 GDExtension**（`addons/limboai`）。
所有自研 BT 框架（BTNode / BTAsset / BehaviorTreeRunner / Blackboard / BTContext / AIInterruptPolicy / AIController 等）已全量删除，无残留代码、无残留场景节点、无残留资源引用。

### 2.4 角色脚本桥接（`Script/Character/EnemyCharacter.gd`）

```text
@onready var bt_player: Node = $BTPlayer

_ready:
  ├─ poise_current = poise_max
  ├─ _setup_ai()         # bt_player.agent_node = "."；写黑板 target = player
  ├─ _wire_damage_to_ai()# hurtbox.damaged → 写黑板 event_took_damage
  ├─ EventBus.poise_broken → _on_poise_broken_signal → 写黑板 event_poise_broken
  └─ EventBus.attribute_changed → _on_attr_changed → HP=0 时 _handle_death（淡出+queue_free）
```

> Blackboard 引用必须用 `Object` 静态类型（LimboAI Blackboard 继承 RefCounted，不是 Resource）。

### 2.5 削韧链路（已稳定）

```text
HitBox 命中 → DamageNode.poise_damage（默认 10）
            ↓
DamagePipeline.execute(target, ..., poise_damage)
   第 5.5 步：target 持 Status.PoiseBroken tag 时伤害 × poise_broken_damage_taken_mul (1.5)
   第 12 步 ：target.apply_poise_damage(poise_damage)
            ↓
EnemyCharacter.apply_poise_damage:
   - 持 Status.PoiseBroken tag 时早退（不削韧、不重置计时）
   - poise_current ≤ 0 → _trigger_poise_broken
            ↓
_trigger_poise_broken:
   1. ASC.add_tag(Status.PoiseBroken)
   2. poise_broken_count += 1
   3. _poise_broken_history.append(now_ms)
   4. poise_current = poise_max
   5. EventBus.emit_signal("poise_broken", self)
            ↓
_on_poise_broken_signal: bb.set_var("event_poise_broken", true)
            ↓
BT 高优先级分支 BTCondition_OnEvent("event_poise_broken") → BTAction_EnterPoiseBroken
   - _enter：开始 poise_broken_duration_sec (5.0) 计时
   - _exit：ASC.remove_tag(Status.PoiseBroken) + EventBus.emit_signal("poise_recovered", self)
```

## 3. 全局规则附加项

- `BTPlayer.behavior_tree` 在 Inspector 注入；运行时 LimboAI 会自行 `duplicate(true)` 防多怪共享同一棵树（无需我们再做深拷贝）。
- 信号 connect/emit 用字符串风格 `EventBus.connect(&"poise_broken", ...)` / `emit_signal(&"poise_broken", ...)`，兼容 EditorScript placeholder 限制。
- 硬度系统（attacker_poise_level）已在 `_on_hurtbox_damaged` payload 中预留 `attacker_poise_level: -1`，实装时由 attacker.Ability 填入即可，BT 端无须改造。

## 4. 修复记录（2026-05-23）

| 问题 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| **EnemyCharacter._setup_ai 报错** | runtime: `Trying to assign value of type 'Blackboard' to a variable of type 'Resource'` | LimboAI Blackboard 继承自 RefCounted（非 Resource），`var bb: Resource =` 静态类型校验失败 | 3 处 `: Resource` → `: Object` |
| **Slime 不切换到追击/普攻** | BT 跑得起来但所有 BTAction 都 fail，看似怪物完全不动 | `_setup_ai` 显式 `bt_player.set("agent_node", NodePath("."))` 把 agent 指到 BTPlayer 自身；BTAction 拿不到 EnemyCharacter 上的 `move_comp` / `asc` | 删除 set agent_node 行；LimboAI 默认 agent_node 留空时 agent = BTPlayer.get_parent() 正好是 EnemyCharacter |
| **EventBus.gd 注释残留** | doc 提到已删除的 `BehaviorTreeRunner` | LimboAI 迁移时漏更新注释 | 注释改为 `EnemyCharacter._on_poise_broken_signal` |
