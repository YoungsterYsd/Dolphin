## NPC 系统（M11 后续，2026-05-21）

### 概述
对话系统已就绪，但需要"真实 NPC"作为载体让玩家在游戏内主动触发对话（而不是 F10 cheat）。

### 落地范围（5 commit）
| # | 文件 | 内容 |
|---|---|---|
| 1 | `Script/Interaction/InteractableTarget.gd` | 抽象基类：display_name / prompt_text / enabled / interact() / get_prompt_anchor() |
| 1 | `Script/Core/EventBus.gd` | 加 2 信号 `interaction_target_entered/left` |
| 2 | `Script/UI/Widgets/InteractionPromptWidget.gd/.tscn` | NPC 头顶「[G] 对话」提示，每帧 WorldProjector.project_pos 投到屏幕；对话开始时强制隐藏 |
| 2 | `Data/Config/HUDLayout_Default.tres` | 加 InteractionPromptWidget mount（slot=Center priority=50）|
| 3 | `Script/Character/NPCActor.gd` + `Scenes/Characters/NPC.tscn` | NPCActor extends InteractableTarget；Area3D 检测玩家进/出范围；interact() 启动 dialogue_graph_id |
| 4 | `Script/Character/PlayerCharacter.gd` | _on_interact_pressed 实装：遍历 group "interactable" 找最近且 enabled 目标，调 .interact(self) |
| 5 | `Data/Manual/Dialogues/npc_elder_greeting.tres` | 村长对话图：8 节点（首次见面 → set_var(met_elder=true) → 已见过分支）|
| 5 | `Scenes/Levels/TestArena.tscn` | 摆 ElderNPC 在 (-3, 0, -3) |

### 自测证据
```
[INFO][NPC] ElderNPC ready (graph=npc_elder_greeting, radius=2.5)
[INFO][UI] register_widget InteractionPromptWidget.tscn handle=15
[INFO][Character] Player interact -> ElderNPC
[INFO][Dialogue] [start] graph=npc_elder_greeting
```

### 设计要点
- **InteractableTarget 通用接口** —— NPC / 物体 / 触发器都用同一接口；玩家按 G 不区分类型，只调 interact()
- **interactable group + 距离查找** —— 玩家不订阅 entered 信号，按 G 时实时找最近目标，避免"刚出范围按 G 仍触发"
- **NPC 默认朝向玩家**（face_player_on_interact）—— 视觉反馈
- **InteractRange 是 Area3D**，不是 PlayerHurtbox 检测，因为 NPC 不是战斗对象
- **对话开始时 InteractionPromptWidget 自动隐藏** —— 避免和对话框视觉重叠

### 现在体验流程
1. 玩家进入村长 2.5m 范围 → 屏幕上方出现「村长 / [G] 对话」（手感像暗黑/黑帝斯）
2. 按 **G** → DialogueRunner 启动 npc_elder_greeting
3. 第一次：村长打招呼 → 询问帮忙 → 选项 → set_var(met_elder=true) → 道谢
4. 离开范围 → 提示消失
5. 再次接近 + G → 走 again_meet 分支「辛苦了，旅人……」
