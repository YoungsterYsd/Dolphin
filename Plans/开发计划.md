# Dolphin 开发计划

> 项目：Dolphin（俯视角 2D/3D，RPG + BossRush）
> 引擎：Godot 4.6 (Forward+)
> 维护规则：每完成一个里程碑由主 agent 更新本文件状态；重大方案变更追加到文末「变更记录」。

## 全局基线（贯穿 M1–M5）

- **Autoload（共 5 个）**：`EventBus` / `GameInstance`（合并 GameStateManager） / `LevelManager` / `AudioManager` / `SettingsManager`
- **2D 优先**：`BaseCharacter` 基类继承 `CharacterBody2D`；3D 接入预留接口（`AnimationComponent` 用策略模式，后续加 3D 实现不改外部 API）
- **GAS 最小可用**：属性 + 技能 + 效果三件套 + GameplayTag 子系统；不做 AbilityTask、CueManager（用 EventBus + 直接播放器替代）
- **Tag 校验模式**：宽松模式（未注册 tag 仅 warning，不中断启动）

# M1 · 基建骨架

**状态**：🟢 已验收

## 制作内容

### 代码清单

| 文件 | 类型 | 内容 |
|---|---|---|
| `Script/Core/EventBus.gd` | Autoload | 集中声明全局 signal（属性变更/技能激活/伤害/死亡/关卡切换/Boss 阶段/UI 事件） |
| `Script/Core/GameInstance.gd` | Autoload | 跨场景持久数据 + 顶层状态机：`enum GameState { BOOT, MENU, PLAYING, PAUSED, GAME_OVER }`；`change_state()` 切换时 emit `EventBus.game_state_changed` |
| `Script/Core/Logger.gd` | 静态工具 | `Logger.info/warn/error(channel, msg)` 带通道前缀 |
| `Script/GameFramework/LevelManager.gd` | Autoload | `load_level(id)` / `unload_current()`（M1 留接口，M5 实装） |
| `Script/Audio/AudioManager.gd` | Autoload | BGM/SFX/UI 三总线接口（M1 留空） |
| `Script/Settings/SettingsManager.gd` | Autoload | 音量/画质/按键（M1 仅做内存版） |
| `Script/Character/BaseCharacter.gd` | Class（继承 `CharacterBody2D`） | 持有 MoveComponent / AnimationComponent / HitboxComponent / HurtboxComponent / ASC 引用；`_ready()` 收集子组件 |
| `Script/Character/Components/MoveComponent.gd` | Node | `set_input_dir(v)` / `move(delta)`；最大速度/加速度参数 |
| `Script/Character/Components/InputComponent.gd` | Node | 读取 InputMap，输出 `input_dir` 信号（玩家专用） |
| `Script/Character/Components/AnimationComponent.gd` | Node | 抽象接口 `play(name)` / `is_playing(name)`；M1 实装 2D 分支（自动找子节点 `AnimatedSprite2D`） |
| `Script/Character/Components/HitboxComponent.gd` | Area2D | 攻击判定，emit `hit(target)` |
| `Script/Character/Components/HurtboxComponent.gd` | Area2D | 受击判定，提供 `take_damage(amount, source)` |

### 配置清单

- `project.godot` 注册 5 个 Autoload
- 创建目录骨架：
  - `Script/{Core,GameFramework,Character/Components,GAS,AI,Items,UI,Audio,Camera,Settings}`
  - `Data/{Attributes,Abilities,Effects,Items,Enemies,Tags,Levels}`
  - `Scenes/{Main,Characters,UI,Levels}`
- InputMap 添加：`move_up` / `move_down` / `move_left` / `move_right`（WASD）/ `ability_1`（鼠标左键）/ `ability_2`（鼠标右键）/ `interact`（E）/ `pause`（Esc）

## 验收标准

### Tag 子系统
- [ ] 未注册 tag 使用时 Logger 报 warning（宽松模式）
- [ ] `GameplayTag.matches("state.buff.haste", "state.buff")` 返回 true
- [ ] 同时叠两个眩晕 GE（计数=2），其中一个先到期，`state.stunned` 仍存在；第二个到期才真正移除
- [ ] Instant 净化 GE 能清除当前所有眩晕 tag（计数清零）

### 属性 / GE / Ability
- [ ] 测试场景：A、B 两个挂 ASC 的节点；A `try_activate("basic_attack")` → B `health` 100 → 90，EventBus 收到 `attribute_changed`
- [ ] 给 A 应用 Duration GE（5s 攻击 -10%），5s 后属性自动恢复
- [ ] 给 A 应用 Periodic GE（每秒 -5 HP，3s），共扣 15 HP
- [ ] CD 中再次 `try_activate` 返回 false 并打印拒绝原因
- [ ] 给 A 施加眩晕 GE → A `try_activate` 被 `tags_blocked` 拦截 → 2s 后自动恢复
- [ ] **规则检查**：通过 rule-keeper 扫描，无 Error 级违规
