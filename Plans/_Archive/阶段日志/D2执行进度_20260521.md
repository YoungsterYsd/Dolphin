### 8.3 关键架构决策（用户已逐项确认）

| 决策点 | 选择 | 备注 |
|---|---|---|
| AbilityTask | **轻量钩子方案**：`_tick` + `wait_event` | 不引入 Lyra 完整体系（≈700 行） |
| GameplayCueManager | **轻量注册表**：CueManager + CueBinding + Tag 父匹配 | 挂 GameInstance 子节点不占 Autoload；不做 GCN Notify Actor / 异步加载 / 网络复制 |
| 字段命名 | **沿用 health/max_health/attack/defense**（不改名为 health_final 等） | HUD AttributeProvider / Boss AI / EnemyCharacter HP 切 Dead 等存量代码 0 改动 |
| Growth 表迁移 | **不改字段名**，由 AttributeResolver._ALIAS_MAP 做兼容映射 | attack → attack_base + attack_final 双写 |
| 衍生公式 | **D2.A 妥协方案**：PrimaryAttributeSet.recompute_derived 入口动态计算 | D6 加 AttributeBasedSource 时再升级；当前 attack_final = (attack_base + attack_bonus) × (1 + attack_mul) |
| 敌人 Set 装配 | **HealthSet + CombatSet 两套**（不挂 PrimaryAttributeSet） | 02 文档锁定；attack/crit_chance 等找不到字段时 DamagePipeline 自动降级 |
| 玩家 Set 装配 | **HealthSet + PrimaryAttributeSet + CombatSet 三套** | mana/max_mana 字段保留在 HealthSet（HUD 兼容） |
| 飘字 4 样式 | **新增 damage_dealt_v3 信号**（v2 保留兼容） | DamagePopupPool 切到 v3，旧订阅方 0 改动 |
| F1 ShowDebug | **GameInstance 自动挂 CanvasLayer 子节点** | 不依赖具体场景，全场景可用 |
