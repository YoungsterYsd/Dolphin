# 技能编辑器（Skill Editor）· M7 扩展开发总结

> **范围**：M7 主体里程碑（已验收）之后，对 `addons/skill_editor/` 与 `Script/SkillSystem/` 的一系列 UX/UI/数据扩展，时间区间 2026-05-19 ~ 2026-05-20。
> **目标**：把"能用的最小可用版"提升为"日常可高效编辑"的工业级编辑器，对齐 UE Sequencer / Godot 内置 Animation 编辑器的体感。
> **状态**：✅ 已落地，待 M8 继续验收时一并复检。
> **维护规则**：本文档随 Skill Editor 后续重大变更追加；不应被 rule-keeper 报告引用为变更源（变更记录走主开发计划）。

## 三、特性清单（按主题分组）

### 3.1 Inspector · 类型化 Form（替代裸 JSON）

`KeyframeFormBuilder.gd`（静态构造器，按 keyframe 子类分派）：

- **AnimationKeyframe**：
  - `time (s)` SpinBox
  - `anim_name`：**LineEdit + OptionButton 组合**（同一行 HBox），LineEdit 在前占满宽度，OptionButton 后置（▼ 按钮形态）
  - `loop` CheckBox
  - `auto_length` CheckBox + `manual_length` SpinBox（auto 关闭时生效；自动取 frame_count/fps）
- **EventKeyframe**：
  - `time (s)` + `kind` OptionButton（8 种 SkillEventKind）
  - 按 kind 渲染**专属 form**：
    - `HITBOX_ENABLE`：node_path / damage_node_index
    - `HITBOX_DISABLE`：node_path
    - `SFX_PLAY`：sfx_id 下拉（自动从 `Data/Config/SfxBindings.tres` 拉列表，未绑定回退手输）
    - `VFX_SPAWN`：vfx_scene_path（带 📁 文件选择器）+ offset_3d（三栏 SpinBox）+ lifetime
    - `PROJECTILE_SPAWN`：projectile_id / direction / speed
    - `CAMERA_SHAKE`：intensity / duration 双滑条
    - `HIT_STOP`：duration_ms 滑条
    - `CUSTOM_SIGNAL`：signal_name + data JSON
  - 折叠的 `▸ raw payload (JSON)` 兜底，专家可直接编辑

**回调拆分**（解决"LineEdit 连续输入失焦"问题）：
- `on_modified`：结构性变更（kind 切换、auto_length 勾选）→ 重建整个 form
- `on_data_changed`：高频字段（anim_name LineEdit、time SpinBox、loop）→ 只刷 timeline 色条，**不重建 form**，焦点保留

**SpriteFrames 联动**：Dock 把 `() -> SpriteFrames` 闭包注入 builder，AnimationKeyframe 的 OptionButton 自动列出当前 PreviewStage 加载的 SpriteFrames 内所有动画名（按字母序）。

### 3.2 Timeline · 自绘时间轴

`TimelineView.gd`（继承 Control）

| 能力 | 实现细节 |
|---|---|
| **关键帧渲染** | 动画轨：彩色色条（半透绿 + 上下边框）+ 锚点菱形；事件轨：橙色菱形 |
| **AnimationKeyframe 色条长度** | `auto_length=true` 从 SpriteFrames 取 `frame_count / fps`；被下一帧 time 与 timeline.duration 截断 |
| **Hitbox 区间色带** | 事件轨上 HITBOX_ENABLE → HITBOX_DISABLE 闭区间渲染半透红色（工具栏 `Hitbox` 开关） |
| **缩放** | Ctrl+滚轮以鼠标 x 为锚点缩放（鼠标处时间不动）；F 键 Fit-to-width；`set_timeline()` 自动 reset |
| **横向滚动** | 普通滚轮 / 中键拖 平移；Ctrl+滚轮缩放；clip_contents 防溢出 |
| **标尺自适应** | `_pick_ruler_step` 优先按帧对齐：取首条 AnimationKeyframe 的 fps → `frame_step×N` 让间距 ≈ 50px；找不到 fps 回退到 1·2·5×10ⁿ |
| **标尺标签** | 帧对齐时显示 `0.20s·f12`（秒 + 帧序号）；非帧对齐显示纯秒数 |
| **吸附 snap** | 拖动关键帧 / 右键添加帧时吸附到帧步长（无 fps 时回退 0.01s） |
| **Playhead** | 黄色竖线 + 顶部三角 + 时间数字；缩放/滚动后落在可视区外只显示边缘指示线 |
| **Scrubbing** | 标尺区按下拖动 → 实时移 playhead，并触发 `playhead_scrubbed` 信号 |
| **HitStop 暂停** | `pause_playhead_for(ms)` 由预览 EventKeyframe.HIT_STOP 触发，让 playhead 暂停指定毫秒 |
| **空格** | 切换 Play/Pause（在 LineEdit/SpinBox 等输入控件聚焦时不抢按键） |

### 3.3 TrackListView · 自绘轨道列表

`TrackListView.gd`

- 与 TimelineView **共享 `RULER_HEIGHT=28 / ROW_HEIGHT=32` 常量**，左右第 0 行屏幕 y 严格对齐：
  - 左：LeftHeader(28) + TrackList y=RULER_HEIGHT(28) = 56
  - 右：TimelineHeader(28) + TimelineView y=RULER_HEIGHT(28) = 56
- 顶部自带 ruler 占位区域（深色背景 + 底部分割线，视觉上与 TimelineView 的 ruler 浑然一体）
- 行渲染：偶数行底色 + 选中高亮 + 4px 左侧色条（动画绿 / 事件橙）+ track 名（带 🎞/⚡ 前缀）
- 单击行 → emit `track_selected` 信号 → Dock 同步 `selected_track_index`

### 3.4 Preview · 固定场景 + Pop Out

#### 3.4.1 PreviewScene.tscn（关键设计）

历史上的"代码动态构建 SubViewport+Camera"经常因 `@tool` 时序导致 viewport.size=0 / camera 未 current / 黑屏。**最终方案**：所有节点全部静态布置在 `addons/skill_editor/dock/preview/PreviewScene.tscn`，脚本只通过 `%unique_name` 引用。

**节点树**：
```
PreviewStage (VBoxContainer + PreviewStage3D 脚本)
├── TopBar (HBoxContainer)
│   ├── HintLabel
│   └── BrowseBtn (📁)
├── ViewportContainer (SubViewportContainer, stretch=true)
│   └── Viewport (SubViewport, own_world_3d=true, render_target_update_mode=ALWAYS)
│       ├── WorldEnv (Environment 完全对齐 main_scene：BG_SKY + ProceduralSky + ACES + SSAO + Glow + Fog)
│       └── World
│           ├── Light (DirectionalLight3D, transform/color/energy 与 main_scene 完全一致)
│           ├── Ground (40×40 PlaneMesh + 灰色 StandardMaterial3D)
│           ├── Sprite (AnimatedSprite3D, billboard=1, alpha_cut=1, shaded=true, pixel_size=0.025, texture_filter=NEAREST)
│           ├── VfxLayer (Node3D, VFX_SPAWN 关键帧实例化目标)
│           └── CameraRig (Node3D, y=0.5)
│               └── SpringArm (pitch=-55°, spring_length=8.0, collision_mask=0)
│                   └── Camera (fov=45, current=true)
└── AudioPlayer (AudioStreamPlayer)
```

**与游戏内 `main_scene.tscn` 的渲染参数严格对齐**（详见 `Data/Config/CameraConfig.tres`）：
- pitch -55°、distance 8.0m、fov 45°、target_y_offset 0.5
- 暖白光 (1, 0.95, 0.85) energy 1.2 + 蓝灰天空 ambient
- Sprite `shaded=true` + 像素 NEAREST 过滤，与游戏内角色显示一致

#### 3.4.2 PreviewStage3D.gd（薄逻辑层）

只负责业务方法，不再构造场景：
- `handle_keyframe(kf)`：路由 AnimationKeyframe / EventKeyframe（SFX_PLAY / CAMERA_SHAKE / HIT_STOP / VFX_SPAWN）
- `sample_animation_at(name, offset)`：Scrub 时定位 sprite 到精确帧并 pause
- `resume_animation()` / `stop_animation()`：Play 时恢复推进 / preview_finished 时停在当前帧（避免 SpriteFrames.loop=true 的 anim 在 timeline 结束后独自循环）
- `cam_zoom(factor)` / `cam_reset()`：调 SpringArm.spring_length
- `_can_drop_data` / `_drop_data` + `📁 Browse` 按钮：双入口设置 SpriteFrames（Dock 内嵌时拖拽可用，Pop Out 时 Browse 兜底）

#### 3.4.3 Pop Out 形态

- 默认内嵌在 `PreviewSlot`（Dock 顶部 VSplit 的上半）
- `🪟 Pop` 按钮 → reparent stage 到 `SkillEditorPreviewWindow`（独立 Window）
- `🪟 Dock` 或关闭独立窗口 → 自动 reparent 回 PreviewSlot
- **共享同一 PreviewStage3D 实例**：SpriteFrames、相机、动画姿态全部不丢

## 四、关键技术决策

| 决策 | 选择 | 否决方案 |
|---|---|---|
| 时间轴 UI | 自绘 Control（TimelineView/TrackListView） | RichTextLabel/编辑器 ItemList（无法画色条 + 标尺） |
| 预览舞台 | **固定 .tscn + 脚本只用 %unique_name 引用** | 代码 `_build_view` 动态构建（@tool 时序问题反复踩坑：viewport size 0、camera 未 current、SubViewportContainer.stretch true/false 反复试错） |
| 数据驱动后端 | 保留 `SkillTimeline.tres + ActiveTimeline 推进` | 迁到 Godot 原生 `AnimationPlayer/Animation` —— 否决：Animation 不能放业务事件 payload，AnimationPlayer 强引用 NodePath 与"技能与施法者解耦"冲突 |
| 标尺刻度 | 帧对齐优先（fps→frame_step×N），回退 1·2·5×10ⁿ | 仅秒数对齐 —— 否决：动画师常按帧思考 |
| 预览相机 / 灯光 | 与 `main_scene.tscn` + `CameraConfig.tres` 严格一致（pitch/distance/fov/光照/天空/SSAO/雾） | 编辑器专属灯光配置 —— 否决：所见非所得 |
| Sprite 过滤 | 显式 `texture_filter = NEAREST` | 依赖 `project.godot` 全局配置 —— 否决：项目级配置变化会破坏预览效果 |
| Inspector form 回调 | `on_modified` / `on_data_changed` 双语义 | 单一 callback —— 否决：连续输入会因 form 重建丢焦点 |
| Pop Out 形态 | reparent 同一实例 | 创建两份 stage —— 否决：状态不同步、SpriteFrames 重新加载 |

## 五、踩坑回顾（已修复）

| 问题 | 根因 | 修法 |
|---|---|---|
| 拖动标尺时 sprite 不切到对应帧 | `_play_animation` 只 `play(name)` 不定位帧 | 加 `sample_animation_at(name, offset)` 用 fps 反推 frame index |
| timeline 结束后角色仍循环 | SpriteFrames.loop=true 与 timeline 完成时机解耦 | preview_finished → `_preview_stage.stop_animation()` |
| 闪白 sprite 失败 | SubViewportContainer.stretch + 独立 Window 渲染异常；shader pass 与 billboard 互斥 | 退化为 modulate 染色（HitFlashController 已沉淀） |
| 预览黑屏 | `SubViewport.size = 0` / `Camera.current=true` 在 add_child 之前 | 节点全部预排在 .tscn 里，避免代码时序问题 |
| 预览贴图发紫 | 自定义 ambient + FILMIC tonemap + glow 把贴图变灰 | 直接照抄 main_scene 的 Environment（ACES + Sky ambient） |
| 预览 sprite 太大 / 角色被切到屏幕底 | `pixel_size=0.045` + `position.y=0.6` + SpringArm.origin.y=1（编辑器手动改偏） | 全部对齐 Player.tscn：`pixel_size=0.025` / `position.y=0.4` / SpringArm origin (0,0,0) |
| 像素美术显示模糊 | 默认 `texture_filter=LINEAR` | Sprite 节点显式 `texture_filter=NEAREST (0)` |
| Tracks 与 Timeline 行 y 偏 28px | TrackListView 没保留 ruler 占位，仅靠 LeftHeader 补 | TrackListView 内重新画 RULER_HEIGHT 顶部留白 |
| LineEdit 不能连续输入 anim_name | `text_changed` → `_refresh_inspector()` 销毁重建 form | 拆 `on_data_changed`（轻量）vs `on_modified`（重建） |
| Preview 面板小 / Inspector 太窄 | 默认 split_offset / minimum_size 不合理 | RightPanel 加宽到 520px；TopPreviewSplit split_offset 180、PreviewSlot min 60 + MainArea min 200（双向可拖） |

## 六、用户操作快查

### 6.1 创建技能时间轴

1. 工具栏右部 `New` 或 `Open` 加载已有 `.tres`（默认目录 `res://Data/Skills/Timelines`）
2. 在 PreviewSlot 顶部点 `📁 Browse...` 选 SpriteFrames.tres（或从 FileSystem dock 拖入）
3. 左下 `+ → + Animation Track` → 自动出现一条 track，含 time=0 的关键帧（默认 anim 已填）
4. 时间轴上**右键** `Add Animation Keyframe @0.20s`（或 `Add Event [sfx_play] @...`）继续叠加
5. 点中关键帧 → 右侧 Inspector 编辑参数

### 6.2 快捷键

| 键 | 功能 |
|---|---|
| `Space` | Play / Pause |
| 鼠标拖标尺 | Scrub（实时定位 sprite 到对应动画帧） |
| `Ctrl + 滚轮` | 以鼠标处为锚点缩放时间轴 |
| 滚轮 / 中键拖 | 横向滚动 |
| `F` | Fit-to-width 重置缩放 |
| `Delete` | 删除选中关键帧 |

### 6.3 调整预览相机

- `Cam: − + ⌂` 工具栏按钮：缩远 / 拉近 / 重置（修改 SpringArm.spring_length）
- 想永久调相机参数 → **直接打开 `addons/skill_editor/dock/preview/PreviewScene.tscn`** 在 Godot 编辑器里调 SpringArm pitch / spring_length / Camera fov 等，所见即所得

### 6.4 与运行时联动

- 编辑器侧产出的 `.tres` 由 `Ability_TimelineDriven` → `SkillTimelinePlayerHost.play()` → `ActiveTimeline.advance()` 驱动
- AnimationKeyframe → `AnimationTrackHandler` → `BaseCharacter.anim_comp.play(name)`
- EventKeyframe → 6 类广播事件经 `EventBus.skill_event_*` 发出，由 AudioManager / VFXSpawner / CameraRig / HitStopHost 等订阅
- 详细路由见 `Plans/二期开发计划.md · M7` 章节

## 七、规则合规

- **R-DATA-02**：所有可调时序参数（关键帧 time / kind / payload / anim_name）走 SkillTimeline.tres，编辑器只是可视化 IO 层；预览侧可调参数（视口尺寸、相机震屏步数、音频静音、上次 SpriteFrames 路径）走 `PreviewStageConfig.tres`；预览相机/灯光参数硬编码在 PreviewScene.tscn（编辑器内可视化即配置）
- **R-LOG-01 例外**：编辑器进程（@tool 脚本）无法访问 GameLogger（运行时 Autoload），统一用 `print() / push_error() / push_warning()`
- **R-EVENT-01**：8 种 EventKind 中 6 种走 EventBus 广播；HITBOX_ENABLE/DISABLE 直管（详见 `SkillEventKind.is_direct()`）
- **R-ARCH-02**：Skill Editor 不新增 Autoload，所有功能内嵌在 EditorPlugin 与 Inspector 子树里
